Database Trigger Runtime Logic

Mathematical model invoked by scheduled daemon every midnight to prevent revenue leakage

MySQL Routine v2.4
Phase 1: Grace Interval
Days 01 to 10

Zero fine applied. Base ₹6,000 due. Automated payment reminder dispatches on day 5 and day 8.

Phase 2: Daily Linear Fine
Days 11 to 30

Flat penalty of ₹50.00/day calculated via (DATEDIFF(NOW(), due_date) * 50.00).

Phase 3: Compounding Surcharge
Day 31+ Onward

Accumulates +1.5% compounding interest per month on unsettled balance, flagged for legal notice.

-- ACID Stored Procedure: Execute Late Fine Batch Computation
CREATE PROCEDURE sp_accrue_overdue_interest()
BEGIN
  UPDATE maintenance_invoices
  SET late_fine_accrued = (DATEDIFF(CURRENT_DATE, due_date) * 50.00) + ROUND((outstanding_balance * 0.015), 2),
      total_payable = base_due + late_fine_accrued - paid_amount,
      status = 'OVERDUE'
  WHERE payment_status != 'PAID' AND CURRENT_DATE > due_date;
END;
