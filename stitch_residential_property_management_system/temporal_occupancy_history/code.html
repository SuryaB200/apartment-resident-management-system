ACID Schema Architecture (Third Normal Form)

Eliminating the Overwritten Spreadsheet Row Anti-Pattern

-- Relational Definition: Occupancy_History
CREATE TABLE Occupancy_History (
occupancy_id VARCHAR(32) PRIMARY KEY,
flat_id VARCHAR(16) NOT NULL REFERENCES Flats(flat_id),
resident_id VARCHAR(32) NOT NULL REFERENCES Residents(resident_id),
move_in_date DATE NOT NULL,
move_out_date DATE NULL, -- NULL = Active Tenancy
tenancy_status ENUM('ACTIVE', 'TERMINATED', 'EVICTED') NOT NULL,
deposit_amount DECIMAL(10,2),
deposit_settled DECIMAL(10,2),
immutable_hash VARCHAR(64) NOT NULL
);

Overwriting flat row with new tenant deletes prior occupant metadata, corrupts previous fiscal year ledger links, and makes legal disputes unprovable.

Every tenant is linked via non-destructive foreign keys. An occupant change writes an archival end-date and appends a new state without wiping prior records.
